# ロードマップ

このスキル自身の開発を追跡するロードマップ。各ループの冒頭で読み、末尾で更新する。
状態: `[ ]` 未着手 / `[~]` 進行中 / `[x]` 完了

## 凡例・使い方

- 上から順（または優先度順）に1ループ1タスクで進める。
- ループ中に新しく必要と分かったタスクは、この一覧に追記してから着手する。
- 完了したタスクは `[x]` にし、対応するループ番号を末尾に添える（例: `(loop 1)`）。

## タスク一覧

- [x] 骨子スキル（SKILL.md）の作成：目的・ゴール・禁止事項・手順・コミット規約を定義 (loop 1)
- [x] ROADMAP.md / HISTORY.md の雛形作成 (loop 1)
- [ ] **目的の記入**（ユーザーが後日追記予定 → 埋まり次第このタスクを完了にする）
- [ ] 目的確定後、ゴールを検証可能な条件へ具体化する
- [ ] ゴールを実タスクへ分解し、この一覧に追記する

## 保留・要確認

- 目的が未確定のため、ゴール以降のタスクは目的の追記待ち。
